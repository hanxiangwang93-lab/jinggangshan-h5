# Triage 标签

技能内部使用五个标准 triage 角色。此文件将这些角色映射到本仓库实际使用的标签字符串。

| Skills 中的标签 | 本仓库标签 | 含义 |
|---|---|---|
| `needs-triage` | `需要评估` | 维护者需要评估此 Issue |
| `needs-info` | `等待回复` | 等待提交者补充更多信息 |
| `ready-for-agent` | `AI可接手` | 描述充分，AI Agent 可直接处理 |
| `ready-for-human` | `需人工` | 需要人工实现 |
| `wontfix` | `不处理` | 不予处理 |

技能中提到某个角色时（如 "打上 AI 可接手的 triage 标签"），使用此表右侧对应的标签字符串。
