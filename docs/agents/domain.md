# 域文档

工程类技能在探索代码库时如何消费域文档。

## 探索前，先读取以下文件

- **`CONTEXT.md`** — 仓库根目录，项目的共享语言/术语表
- **`docs/adr/`** — 架构决策记录，先读与当前工作相关的 ADR

如果这些文件不存在，**静默跳过**。不要主动提示创建，`/grill-with-docs` 技能会在术语或决策实际产生时延迟创建它们。

## 文件结构

单一上下文仓库：

```
/
├── CONTEXT.md
├── docs/adr/
│   ├── 0001-xxx.md
│   └── 0002-xxx.md
└── src/
```

## 使用术语表的词汇

输出中引用领域概念时（Issue 标题、重构提案、假设、测试名），使用 `CONTEXT.md` 中定义的术语。不要漂移到术语表明确避免的同义词。

如果需要使用的概念不在术语表中，要么是你在发明项目不用的话语（重新考虑），要么是确实有缺口（记下来，留给 `/grill-with-docs`）。

## 标记 ADR 冲突

如果输出与现有 ADR 矛盾，明确标出而不是静默覆盖：

> *与 ADR-0007（事件溯源订单）矛盾 — 但值得重新讨论，因为……*
